# Transgender HRT Information Site

A Hugo static site providing basic information about male-to-female hormone replacement therapy.

## Features

- Comprehensive information about MTF HRT
- Topics covered: Overview, Hormones, Effects & Timeline, Safety, Resources
- Clean, responsive design
- Educational disclaimers throughout

## Building the Site

### Prerequisites

Install Hugo (v0.123.7 or later):

```bash
# Ubuntu/Debian
sudo apt-get install hugo

# macOS
brew install hugo

# Or download from https://gohugo.io/installation/
```

### Build

```bash
hugo
```

The site will be generated in the `public/` directory.

### Development Server

```bash
hugo server
```

Then open http://localhost:1313 in your browser.

## Content

- **Home** (`content/_index.md`) - Introduction and overview
- **Overview** (`content/overview.md`) - Understanding MTF HRT process
- **Hormones** (`content/hormones.md`) - Types of medications used
- **Effects** (`content/effects.md`) - Timeline and changes to expect
- **Safety** (`content/safety.md`) - Monitoring and health considerations
- **Resources** (`content/resources.md`) - Support organizations and references
